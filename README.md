## About OmniShowcase

**OmniShowcase** generates videos of a specific object from a few multi-view reference images along diverse camera trajectories, up to full 360° orbits. It conditions a Wan2.1 image-to-video model, adapted with lightweight LoRA, on a turntable of surface-normal maps reconstructed from the references, keeping the subject's identity and 3D structure consistent as the viewpoint changes. We also release **Showcase-4K**, a synthesized training corpus spanning twelve camera motions, and **ShowcaseBench**, an evaluation set with source meshes and camera parameters.
